# 百法难治 AI 新闻

AI 新闻内容与发布站点的主仓库。

## 三层架构

- **Google Sheets**：选题、状态、来源链接、发布数据。
- **Google Drive**：研究证据、截图、视频、图片和版权资料，所有素材统一存放在这里。
- **本仓库**：最终审核后的 Markdown/MDX 文章、素材引用链接、网站代码与发布历史。

## 目录

- `content/news/`：正式文章（Markdown/MDX）
- `docs/`：流程、写作规范和数据契约
- `site/`：新闻站点代码（后续接入）
- `.codex/`：本项目的 Codex 工作约定（可选）

## 媒体规则

图片、视频、截图和其他大文件不提交到 GitHub。文章通过 Google Drive 的公开或受限链接引用素材；只有确认可以公开访问的 Drive 文件，才能用于公开文章。

## 发布原则

Drive 中的研究资料不是正式文章版本。文章必须先经过审核，再合并到默认分支并发布。
