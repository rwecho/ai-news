# 百法难治 AI 新闻

AI 新闻内容与发布站点的主仓库。

## 三层架构

- **Google Sheets**：选题、状态、来源链接、发布数据。
- **Google Drive**：研究证据、截图、视频、图片和版权资料。
- **本仓库**：最终审核后的 Markdown/MDX 文章、网站代码与发布历史。

## 目录

- `content/news/`：正式文章（Markdown/MDX）
- `public/media/`：已确认可公开使用的媒体资源
- `docs/`：流程、写作规范和数据契约
- `site/`：新闻站点代码（后续接入）
- `.codex/`：本项目的 Codex 工作约定（可选）

## 发布原则

Drive 中的研究资料不是正式文章版本。文章必须先经过审核，再合并到默认分支并发布。
